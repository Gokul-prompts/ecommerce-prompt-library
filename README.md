# E-commerce Ad Copy Prompt Library

Welcome to my prompt engineering portfolio. 

I am a Computer Science graduate building practical AI prompt systems for e-commerce advertising. This repository is a living library of prompts I have designed, tested, and documented for generating ad copy, product descriptions, and marketing angles.

## 📂 How this library is structured
Each prompt in this library includes:
1. **The Prompt:** Ready to copy/paste into ChatGPT, Claude, or Gemini.
2. **Sample Input:** A test product used to run the prompt.
3. **Sample Output:** The actual result generated by the AI.
4. **Why it works:** The prompt engineering technique used (e.g., role prompting, few-shot, constraints).
